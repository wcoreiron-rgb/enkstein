Platform Engines

Always-On Intelligence. Built In.

Beyond the 26 security claws, these core engines run continuously to govern every action, agent, and workflow.

🛡️
Trust Fabric
Central zero-trust enforcement — 6-stage pipeline evaluating every security action before it executes. Policy eval, risk scoring, anomaly detection, immutable audit.
🔄
Swarm Orchestration
Parallel multi-agent investigation with planner, dispatcher, judge synthesis, SSE live stream, suspicious-identity presets, and ticket handoff to Jira/PagerDuty.
🚨
Autonomous Remediation
Finding → playbook matching → action execution → human approval gate → one-click rollback. 5 built-in playbooks, Okta/Entra/AWS/CrowdStrike integrations.
💍
Execution Ring Policy
4-tier privilege isolation: ring0 (blocked), ring1 (2 approvals), ring2 (trust-gated), ring3 (auto-allow). Deterministic execution_ring_violation deny reason on all violations.
📡
Channel Gateway
Normalizes Teams, Slack, webhook, email, and CLI commands into a single policy-governed CommandClaw contract. Multi-operator approval, bulk review, timeline audit.
🏥
SRE Policy Engine
Circuit breaker, error budget enforcement, and SLO primitives for all governed modules. Cascading failure prevention tested against OWASP ASI-08.
🔐
Connector Provenance
SHA-256 content hash + Ed25519 signature verification at skill pack install time. Unsigned community packages warn; tampered manifests are blocked.
🌐
External Agent Control
Remote agent registration, heartbeat, tenant-scoped dispatch, allowed-intent enforcement, and kill-switch. Every agent has a cryptographic identity via Ed25519 signing.

Zero Trust Principles

Six Pillars of Governed Security

RegentClaw operationalizes zero trust beyond network segmentation — enforcing governance at every layer of the security stack.

🪪
Every component has identity
Agents, claws, workflows, and service accounts are first-class identity principals. Non-human identities are governed alongside human ones.
🔐
Every action is authorized
No security action executes without passing policy evaluation, risk scoring, and (when required) human approval via the Trust Fabric pipeline.
👁️
Every runtime is monitored
Behavioral baselines for all claws and agents surface anomalies in real time, before policies are even invoked.
🧾
Every workflow is attributable
The immutable audit log captures the full decision chain — who triggered what, which policies matched, what risk score was assigned, and what happened.
🚧
Every risk is containable
Emergency mode provides instant containment actions. Each claw can isolate its scope without requiring full platform access.
⚙️
Every module is governed
All 26 claws share the same governance layer — there are no escape hatches, no unmonitored paths, and no ungoverned execution modes.
Quick Start

Up and Running in Minutes

RegentClaw is fully containerized. A single docker compose up starts the entire stack — backend API, frontend, PostgreSQL, and Redis.

Fully self-hosted. Your credentials stay on your machine — encrypted at rest, never sent anywhere. Add your own API keys via the Connectors UI and each Claw connects to your real environment.

Security: Never commit backend/.secrets/ to git. This folder holds your encryption key and is gitignored by default. Each deployment generates its own isolated key on first run.

How to add your credentials →
🐚 bash 
# Clone and start
git clone https://github.com/wcoreiron-rgb/regentclaw
cd regentclaw
docker compose up --build

# Open the platform
# Dashboard: http://localhost:3000
# API Docs:  http://localhost:8000/docs

# Add your own credentials
# → Go to Connectors → click any connector
# → Enter your API key/token — encrypted at rest
# → Claw switches from demo data to your real environment
